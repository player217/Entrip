# Entrip 요구사항 정합성

과거 요구 검토 결과, 기존 디자인을 유지하고 최신의 2단 예약 편집 방식을 기준으로 복구했습니다. 이전 3열 편집안보다 최신 요구를 우선합니다.

| 요구 | 반영 위치/동작 |
| --- | --- |
| 기존 파란색·흰색 UI 유지 | Header/Sidebar/AppFrame, 공통 입력·탭 |
| 2단 예약 편집 | BookingEditor: 좌측 기본·고객 정보 / 우측 호텔·항공·차량·기타 반복 추가 |
| 월간·주간 캘린더와 목록 | BookingWorkspace 공통 데이터·편집기, 날짜 클릭 등록 |
| 실제 저장·수정·이력·인쇄 | v2 Booking/BookingHistory, If-Match 충돌 처리, 인쇄 팝업 |
| 회사·역할 선택 및 회사별 데이터 | 데모 로그인 선택기, 서버 DB 기반 인증·회사 필터 |
| 독립 작업 탭 | 탭별 초안·편집 ID, 재접속 복원, 순서 변경·닫기 확인 |
| 실시간 업무 메신저 | 회사 직원 목록→1:1, 기존 방 초대, DB 저장·Socket 수신 |
| 계좌·입출금·순차 결재 | BankAccount 분리, 승인 거래 잔액, 지정 결재 순서·본인 승인 차단 |
| 직원 관리 | 관리자 추가·수정·활성/비활성, 기존 계정 DB 보존 |
| 항공사×요일 다중 시간표 | 실제 원본 시각·과거 자료·조회 실패 표시 |
| 대시보드·통계 | 실제 예약, 월말·날짜·취소 제외, 통화 분리 및 원가 누락 표시 |
| 운영 준비 | v2 빌드, 빈 DB/기존 DB 마이그레이션, 실행 파일·운영 문서 |

외부 메일·OCR·자동화 실행과 운영 배포는 이 코드의 완료 기능으로 표시하지 않습니다. 확인되지 않은 외부 연결을 성공처럼 보이게 하던 예시 화면은 미설정/미구현 상태로 바꿨습니다. 원본 DB 변환의 검증 범위는 `V2_SCHEMA_MIGRATION_20261117.md`에 기록했습니다.
