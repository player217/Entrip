# Entrip 예약 입력과 인쇄 검증

예약을 캘린더에서 만들고 저장한 뒤 목록에서 다시 열어 입력값을 확인했다. 같은 예약을 앱의 인쇄 버튼과 브라우저 인쇄로 출력했다. 검증에 사용한 예약·직원·메시지는 테스트용이다.

## 이전 요청과 실제 입력창

| 요청 | 구현과 확인 |
| --- | --- |
| 넓은 예약 창, 제목 ‘예약 정보’, 오른쪽 상단 취소·저장·인쇄 | 데스크톱 1440×900에서 창은 1186×667로 16:9다. 800px와 390px 화면에서는 한 열로 바뀌며 세 버튼을 모두 사용할 수 있다. |
| 기본·고객 정보와 반복 여행 항목을 좌우로 배치 | 2026년 7월 30일에 요청한 2단을 적용했다. 왼쪽에 팀명·팀 유형·예약 상태·인원·담당자·고객·대표자·연락처·금액, 오른쪽에 항공·호텔·차량·기타를 배치했다. 각 항목은 여러 건 추가·수정할 수 있다. |
| 캘린더에서 선택한 날짜로 예약 시작 | 11월 18일의 등록 버튼으로 연 창에서 출발일과 귀국일이 모두 11월 18일인 것을 확인했다. |
| 기존 예약도 다시 열고 수정 | 구형 왕복 데이터를 출국·귀국 두 행으로 열어 도착 시각과 팀 유형을 수정했다. 저장 후 원래 예약 참조번호, 운임 메모, 호텔 데이터, 연결된 항공·호텔·차량·정산을 확인했다. |
| 예약서에 실제 입력값 표시 | 저장 전에는 입력 중인 값, 저장 후에는 다시 열어 확인한 값으로 출력한다. 항목별 수량·단가·합계와 통화별 소계, 판매금·입금·잔금을 구분했다. 가격 미입력과 입력한 0도 다르게 표시한다. |

## 조회 화면에서 PDF로 이어지는 내용

| 화면 | PDF에서 대조한 내용 |
| --- | --- |
| 월간·주간 캘린더, 캘린더 실적 | 선택 기간과 조건, 날짜별 달력·예약 요약 및 예약 명세를 확인했다. 밀집 월간 달력 4쪽에서 같은 날의 생략 건수와 전체 예약 명세까지 133개 항목을 대조했다. |
| 월간·주간 예약 목록 | 현재 조회 조건·기간·페이지의 예약을 대조했다. 여러 장에 걸친 목록에서도 행 단위로 이어진다. |
| 예약 정보 | 저장된 예약, 수정 중·저장 전 예약, 구형 예약, 브라우저 직접 인쇄를 확인했다. 여행 항목 41건은 A4 세 장에 걸쳐 출력됐고 41개 금액 행의 항목명·수량·단가·합계가 일치했다. |
| 대시보드·종합 통계 | 조회 집계, 알림, 팀 현황, 차트 수치와 단위를 출력한다. 알림 제목이 앞장 끝에 홀로 남거나 팀 현황 한 건이 장 사이에서 갈라지던 인쇄 배치를 수정했다. |
| 항공 운항 일정 | 조회한 노선의 항공사별 월~일 표를 출력한다. 부산→오사카·울란바토르 두 노선에서 시간·편명의 PDF 좌표를 42개 요일 칸과 대조했다. 운항이 없는 칸과 에어부산 하루 두 편을 포함한다. 자료 기준일은 출력물에 표시한다. |
| 계좌·입출금·결재 | 조회한 계좌와 거래, 결재 상태·결재 순서, 작성 중인 계좌·입출금·결재 문서를 각각 출력했다. |
| 메신저 | 대화 검색, 선택한 대화의 발신자·시각·메시지, 직원 찾기·초대 화면을 확인했다. 같은 대화에서 이전 메시지를 불러오기 전 50건, 불러온 뒤 58건이 출력됐다. |
| 설정·직원 | 검색한 직원 목록과 편집 중인 직원 양식을 따로 출력했다. 직원 비밀번호와 다른 탭의 내용은 PDF에 포함되지 않았다. |
| 메일·Flow·빈 작업 탭·로그인 | 외부 서비스가 연결되지 않은 상태와 빈 작업 탭을 화면대로 출력했다. 로그인 화면의 입력값이 인쇄물에 들어가지 않는 것을 확인했다. |

## 검증 방법과 범위

PDF 42건, 총 61쪽을 확인했다. 기본 27개 인쇄 시나리오에서 화면 또는 예약 원본의 값 740개가 PDF에 일치했다. 별도로 14개 추가 인쇄물과 구형 예약 1건을 대조했다. 최종 Windows ZIP에서는 웹·공유 패키지 테스트 386개와 API 테스트 93개가 통과했다.

실제 PostgreSQL과 API로 실행한 앱에서 Chromium으로 각 메뉴를 조작하고 인쇄용 CSS를 적용한 PDF를 저장했다. 원본 PDF에서 문자를 추출해 조회·입력값과 비교하고, 각 쪽을 이미지로 렌더링해 표의 열 위치, 한글, 잘림, 빈 장과 페이지 분할을 검사했다. 항공 검증에는 저장소에 포함된 운항 일정 스냅샷을 사용했다. 인쇄 장치별 용지 여백·드라이버는 이번 검증 범위에 포함되지 않는다.
